# Draft arrangement, not a religious revision

`readingCatalogue` is a presentation join; original JSON, translations, IDs and audio are unchanged. The four main wudu sections retain their full bodies. Existing Hanafi wudu sections are inserted beside the corresponding hands, mouth/nose/face, arms, head/ears/feet sections in their existing source order. Their entire paragraphs, including qualifications and review warnings, are retained rather than extracting/rewriting Arabic. The legacy and canonical wudu entries resolve to the same guide to avoid duplicate topics; all legacy data remains in the repository.

Every inserted section is tagged `DRAFT_PENDING_REVIEW` and labelled in the reader. Missing stage-specific dhikr bindings and ghusl show “Source needed”; no ghusl invocation or Arabic formula was invented. This is not approval of any limb-specific prayer, neck-wiping account or existing translation. All original audit content questions remain open.

The post-wudu Arabic section is the last section/slide; its original shared-source/review paragraph is retained as a related source note within that same last section, with its own original ID. Existing source titles/URLs are included unchanged. The existing source-review notice stays visible. Search and old `shared-source` links resolve to this containing section. Long content may scroll within the slide.

Legacy topic keys and notes are never deleted by migration. Old post-wudu topic stars gain a school/language-scoped section bookmark; old wudu stars match the canonical topic. Original links and last-reading IDs resolve through aliases. Explicit user removal can remove a star, as before. Migration uses the saved school/language after visibility recovery because old whole-topic stars had no separate school/language provenance; it never infers another school's wording. This assumption requires user review.

No scholar sign-off, exact dhikr attribution, phone persistence or live navigation verification is claimed. Core tests cover source equality, order, final section, school isolation, search, aliases and idempotent bookmark migration.
