- مقایسهٔ چاپی کامل نشده است. برای بستن پرونده، اسکن قابل دسترسیِ چاپ دقیق و ضمیمهٔ مورد نظر، نظر عالم حنفی و بازبین زبان لازم است. فهرست دقیق تمام فیلدهای خالی/علامت‌دار در پیوست JSON و Markdown آمده است.
