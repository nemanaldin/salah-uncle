# Compact quick access

The shortcut order, original round artworks, tags and destinations are unchanged. The finite grid uses three columns at 320dp available content width or wider and two below that, or when the effective system × app font scale exceeds 1.3. A 360dp phone with the existing 20dp page margins therefore gets three columns at normal text size. Each card has a 56dp image in a 60dp circular theme-colored ring, a two-line label, 8dp padding/gaps, a Material ripple and at least 48dp hit height. Large text grows card height; text is not artificially scaled down. If unusually long labels exceed two lines, visual ellipsis is possible; semantics retain the full label. Real-script clipping requires device inspection.

All card colors and shapes use the existing Material theme. The existing photo palette/overlay values were moved unchanged to ColorTokens.kt; no new colors were invented. Five Compose previews cover light/dark, narrow Urdu, Bengali 200% and Pashto 150%. These previews compile; they were not rendered on a connected Android device. Three layout-policy unit tests cover normal width, narrow width and accessibility scaling. A new Android test covers card presence/clicks at 200% in both layout directions; it is compiled, not executed because no adb target is available.
